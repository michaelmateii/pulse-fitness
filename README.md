# Pulse Fitness

A responsive multi-page website for a fictional gym, built as part of my studies in responsive web design.

The project focuses on responsive web design, usability and creating a consistent experience across desktop, tablet and mobile devices.

## Live Demo

https://michaelmateii.github.io/pulse-fitness/

## Features

- Responsive design for desktop, tablet and mobile
- Four-page website
- CSS Grid layouts
- CSS-only mobile navigation menu
- Responsive training schedule
- Membership comparison
- Semantic HTML5 structure
- Keyboard focus indicators
- Mobile scroll-to-top navigation

## Pages

- Home
- Classes & Schedule
- Membership
- About

## Technologies

- HTML5
- CSS3
- CSS Grid
- Media Queries
- GitHub Pages

No JavaScript frameworks or external CSS frameworks were used.

## Accessibility

The project includes semantic HTML, alternative text for images, keyboard focus indicators and clear navigation.
